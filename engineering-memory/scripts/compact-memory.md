# Memory Compaction Procedure

Run this manually or ask Codex to run it after many bug fixes.

## Goal
Keep memory useful and small.

## Procedure
1. Review `bugs/bug-ledger.md` for repeated root causes.
2. Promote repeated issues into `bugs/recurring-patterns.md`.
3. Promote stable prevention rules into `rules/active-rules.md`.
4. Move outdated rules into `rules/deprecated-rules.md`.
5. Move unresolved systemic problems into `tech-debt/debt-register.md`.
6. Update `metrics/issue-stats.md`.
7. Keep `rules/active-rules.md` short and high-value.

## Principle
Do not let memory grow forever. Convert logs into patterns, patterns into rules, and outdated rules into archives.
